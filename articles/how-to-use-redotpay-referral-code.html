Why You Must Enter the Referral Code During Registration

Step 2: Enter and Verify the Invite Code (sg6r9)

On the registration form, look for the field titled "Referral Code (Optional)". While marked optional by the system, it is required to activate the $5 bonus promotion. Ensure the code matches sg6r9 before tapping "Next" or "Submit".

Step 3: Complete Identity Verification (KYC)

  1. Go to Profile > Identity Verification.
  2. Select your issuing country and ID type (Passport, ID Card, or Driver's License).
  3. Take a clear, non-glare photo of your ID.
